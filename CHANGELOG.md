# Changelog

## 0.1.1

- Verified archive-based GitHub installation with npm 12.
- Added explicit per-command permission for remote package installation and disabled install scripts in the pinned launch example.

## 0.1.0

- Catalog of 48 published Happy Endpoint APIs with separate API guides.
- 1,106 GET operation schemas extracted from public request documentation and verified PropertyFinder MCP metadata.
- Four MCP tools for source search, operation search, schema inspection and validated requests.
- Local stdio transport with a user-supplied RapidAPI key.
- Free-plan setup, practical agent workflows and troubleshooting.
- Bounded response previews, credential redaction, request timeouts and disabled redirects.
